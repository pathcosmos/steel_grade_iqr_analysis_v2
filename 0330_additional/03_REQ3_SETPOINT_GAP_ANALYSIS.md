**필요 태그 목록**:

**데이터 소스**: MES, Level 2 제어시스템, PLC 설정값 로그

### 2. 강종×사이즈×계절별 정상 조업 범위 산정

**목적**: 조건별 정상 범위를 산정하여 관리 기준 도출

**분석 매트릭스**:

| 조건 변수 | 수준 | 비고 |
|----------|------|------|
| 강종 | B5, D4, D5, N5 | 4수준 |
| 사이즈 | D10, D13, D16 등 | 강종별 상이 |
| 계절 | 봄(3~5), 여름(6~8), 가을(9~11), 겨울(12~2) | 4수준 |

**산정 방법**:

```
정상 범위 = RUN 상태 & 불량 미발생 코일의 [Q10, Q90] 구간
관리 상한(UCL) = Q90 + 1.5 × IQR
관리 하한(LCL) = Q10 - 1.5 × IQR
경보 한계(UAL/LAL) = ±2.0 × IQR
```

**출력 예시**:

| 강종 | 사이즈 | 계절 | 태그 | 정상 범위 | 관리 상한 | 관리 하한 | 경보 상한 | 경보 하한 |
|------|--------|------|------|----------|----------|----------|----------|----------|
| D5 | D10 | 겨울 | 가열로 압력 | 0.48~0.52 | 0.54 | 0.46 | 0.56 | 0.44 |
| D5 | D10 | 겨울 | PR3 토크 | 30~45 | 52 | 23 | 60 | 15 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... |

### 3. Gap 이탈 시 불량 확률 정량화

**목적**: Gap이 일정 이상일 때 불량 발생 확률을 수치화

**방법**:
- Gap 구간별 (0~5%, 5~10%, 10~20%, 20%+) 불량률 산출
- Logistic Regression으로 Gap → 불량 확률 모델링
- 각 태그별 "위험 Gap 임계값" 도출

**출력 예시**:

| 태그 | Gap 구간 | 불량률 | 위험도 |
|------|---------|--------|:------:|
| 가열로 압력 | 0~2% | 1.2% | 정상 |
| 가열로 압력 | 2~5% | 3.8% | 주의 |
| 가열로 압력 | 5~10% | 8.5% | 경보 |
| 가열로 압력 | 10%+ | 15.2% | 위험 |

### 4. 계절 영향 분석

**목적**: 계절(외기온)에 따른 설정값-실제값 Gap 변동 파악

**방법**:
- 2025.03~08 (봄~여름) vs 2026.01~02 (겨울) 비교
- 가열로 관련 태그는 계절 영향이 클 것으로 예상 (외기온 → 로내 열손실)
- 냉각수 온도/유량도 계절별 차이 예상

## 설정값 데이터 없을 경우 대안 (실행 계획 B)

설정값 확보가 불가능한 경우 **요구사항 #3을 "실측값 기반 관리 기준 도출"로 범위 축소하여 실행**합니다.

> **선언**: 설정값 미확보 시 "설정값 vs 실제값 Gap 정량화"는 실행 불가. 대신 "정상 조업 범위 산정 + 관리 기준 도출"로 대체하여 고객 요구의 핵심(관리 표준 제시)을 충족합니다.

### 대안 실행 방법

1. **정상 조업 범위 산정**: RUN 상태 & 불량 미발생 코일의 [Q10, Q90]을 "실질 관리 범위"로 설정
2. **이탈 지표 산출**: 불량 코일 평균값과 정상 범위의 거리를 "실측 Gap"으로 정의
3. **강종×사이즈×계절별 세분화**: 조건별 관리 기준표 제시
4. **이탈 시 불량 확률**: 실측값 구간별 불량률로 Logistic Regression 대체

### 대안 산출물 예시

| 강종 | 사이즈 | 계절 | 태그 | 정상 범위(Q10~Q90) | 불량 평균 | 실측 Gap | 관리 하한 | 경보 하한 |
|------|--------|------|------|:------------------:|:--------:|:--------:|:---------:|:---------:|
| D5 | D10 | 겨울 | 가열로 압력 | 0.48~0.52 | 0.47 | -2.1% | 0.46 | 0.44 |
| D5 | D10 | 겨울 | PR3 토크 | 30~45 | 27.3 | -9.0% | 23 | 15 |

### 대안 vs 원안 비교

| 항목 | 원안 (설정값 확보 시) | 대안 (실측값 기반) |
|------|:-------------------:|:-----------------:|
| Gap 정량화 | 설정값-실제값 차이 | 정상 범위-불량 평균 차이 |
| 관리 기준 | 설정값 ± 허용 편차 | Q10~Q90 + IQR 기반 |
| 계절/강종/사이즈 반영 | O | O |
| 불량 확률 모델 | Gap 기반 Logistic | 실측값 기반 Logistic |
| **고객 핵심 요구 충족** | **완전** | **부분 (관리 기준은 제시 가능)** |
