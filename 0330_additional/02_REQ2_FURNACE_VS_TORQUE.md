# 요구사항 #2: 가열로 vs 토크 — 우선순위 선후관계 파악

## 고객 요청 원문

- 두 변수(가열로, 토크) 모두 변동성 우선순위가 높음
- **필요 작업**: 어느 것이 선행 지표인지 파악 → 선제 조치 방향 제시

## 추가 요청 (공정 흐름 방향성)

현업에서 제기한 2가지 가설:

1. **정방향**: 조압연/사상압연 영향 → 가열로가 영향받음 → Stand 8 등에 전파
2. **역방향**: 가열로에서 영향 → 중간압연/사상압연으로 전파

### 현재까지의 결론

- 가열로 압력과 PR3 토크는 **독립적 인자**로 각각 확정
- 두 인자 간 **선후관계(lag)**는 분석되지 않음
- 공정 흐름 기반 물리적 순서: 가열로 → 조압연 → 중간압연 → 사상압연 → 핀치롤

## 추가 조사 필요 사항

### 1. Cross-Correlation (시차별 상관) 분석

**목적**: 가열로 태그 변동과 토크 태그 변동 간 시간차(lag) 파악

**분석 쌍**:

| 선행 후보 | 후행 후보 | 기대 lag | 물리적 근거 |
|----------|----------|---------|-----------|
| 가열로 압력 | PR3 토크 | 수분~수십분 | 가열 불균일 → 압연 부하 변동 |
| 가열로 압력 | Stand 8 토크 | 수분 | 가열 불균일 → 조압연 부하 |
| MAIN_GAS_FLOW | 가열로 압력 | 수초~수분 | 가스 유량 → 로내 압력 변화 |
| PR3 토크 | 가열로 압력 | (역방향 검증) | 압연 피드백 → 가열로 조정? |
| Stand 8 토크 | Stand 14 토크 | 수분 | 조압연 → 사상압연 전파 |

**방법**:
- `scipy.signal.correlate` 또는 `statsmodels.tsa.stattools.ccf`
- lag 범위: -30분 ~ +30분 (1분 단위)
- RUN 상태 데이터만 사용 (TRANS/IDLE 제외)

### 2. 공정 흐름 기반 인과 경로 매핑

**목적**: 물리적 공정 순서와 데이터 분석 결과의 정합성 검증

**공정 순서**:
```
가열로 → 조압연(Stand 1~6) → 중간압연(Stand 7~10) → 사상압연(Stand 11~14) → 블록밀 → 핀치롤(PR1~4) → 권취
```

**검증 항목**:

| 구간 | 검증 내용 | 방법 |
|------|---------|------|
| 가열로 → Stand 1~6 | 가열 불균일이 조압연 부하에 영향? | 가열로 온도 편차 → Stand 1~6 토크 lag 분석 |
| Stand 1~6 → Stand 7~10 | 조압연 이상이 중간압연으로 전파? | Stand 6 토크 → Stand 8 토크 lag 분석 |
| Stand 7~10 → Stand 11~14 | 중간압연 → 사상압연 전파? | Stand 10 토크 → Stand 14 토크 lag 분석 |
| Stand 11~14 → 핀치롤 | 사상압연 → 핀치롤 전파? | Stand 14 토크 → PR3 토크 lag 분석 |
| 가열로 → 핀치롤 (직접) | 가열로가 핀치롤에 직접 영향? | 가열로 압력 → PR3 토크 전체 lag 분석 |

### 3. 선제 조치 방향 도출

**목적**: 선행 지표 확정 후 어디를 먼저 관리해야 하는지 제시

**시나리오별 권고**:

| 결과 | 의미 | 선제 조치 |
|------|------|----------|
| 가열로 → 토크 (정방향 확인) | 가열로가 근본 원인 | 가열로 압력/온도 관리 강화 |
| 토크 → 가열로 (역방향 확인) | 압연 부하가 가열로에 피드백 | 압연 설정 최적화 우선 |
| 양방향 (상호 영향) | 복합 원인 | 가열로 + 핀치롤 동시 관리 |
| 독립적 (상관 없음) | 각각 별개 원인 | 각 설비 독립 관리 기준 설정 |
