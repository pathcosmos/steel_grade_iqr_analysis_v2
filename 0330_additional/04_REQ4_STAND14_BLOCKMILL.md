# 요구사항 #4: Stand 14 & 블록밀 재검토

## 고객 요청 원문

- 예상과 달리 해당 구간에서 변동성/불량이 크지 않은 결과가 나옴
- **필요 작업**: 해당 설비 구간 중점 재분석

---

## 기존 분석 결과

### Stand 14

| 분석 | 결과 | 판정 |
|------|------|------|
| 전체 데이터 | 토크 -39.1% (p=1.3e-07) | 유의 (표면적) |
| RUN 필터 적용 | 토크 -1.5% (비유의) | **거짓 신호** |
| 강종별 방향 | D5: 토크↓, N5: 토크↑ → 방향 반전 | **Simpson's Paradox 의심** |
| 315분석 | 상위 진입 안 됨 | 가열로 영역이 독점 |

**기존 판정**: TRANS/IDLE 혼입에 의한 거짓 신호. 순수 공정 인자 아님.

### 블록밀 (Finishing Block)

| 분석 | 결과 | 판정 |
|------|------|------|
| FB 마스터 토크 | 전체 -35.4% (p=7.4e-06) | 유의 (표면적) |
| RUN 필터 적용 | 거짓 신호 (TRANS/IDLE 영향) | **거짓 신호** |
| FB 속도 | 전체 -13.2% → 부분 유지 | **약한 신호** |
| 315분석 | PLC 커버 있음 (데이터 양호) | 스탠드만큼 강한 신호 없음 |

**기존 판정**: 토크는 거짓 신호, 속도는 약한 신호.

---

## 현업 의문

> "Stand 14와 블록밀은 공정상 중요한 구간인데 왜 변동성/불량 영향이 작게 나오는가?"

### 가능한 설명

1. **TRANS/IDLE 혼입**: RUN 필터 적용 전에는 유의했으나, 실제 가동 중 데이터에서는 차이 소멸
2. **가열로 영향이 지배적**: 근본 원인이 가열로에 있어 후공정은 "결과"만 반영
3. **데이터 해상도 부족**: ±30초 매칭으로는 미세한 변동을 포착하지 못할 가능성
4. **강종별 상쇄**: D5와 N5가 반대 방향이라 전체 데이터에서 상쇄
5. **블록밀 자체 제어가 양호**: 블록밀 자동 제어가 잘 작동하여 변동이 작을 수 있음

## 추가 조사 필요 사항

### 1. RUN 상태만 필터링 후 Stand 14 재분석

**목적**: TRANS/IDLE 제외 후 Stand 14에서 진짜 유의한 신호가 있는지 확인

**방법**:
- OPERATION_STATUS = 'RUN' 필터 적용
- Stand 14 토크, 속도, 전류 등 관련 태그 전수 검사
- Mann-Whitney U, Cohen's d, RUN 전용 분석

### 2. 강종별 Stand 14 분리 분석

**목적**: D5와 N5 방향 반전(Simpson's Paradox) 확인 및 강종별 메커니즘 규명

**분석 매트릭스**:

| 강종 | 사이즈 | Stand 14 토크 방향 | 불량 유형 | 가설 |
|------|--------|:------------------:|----------|------|
| D5 | D10 | ↓ (저하) | 토션? | 핀치롤 장력 부족과 연결? |
| D5 | D13 | ? | ? | 사이즈별 차이 확인 |
| N5 | D16 | ↑ (상승) | 누워감김? | 과압연? |
| B5 | - | ? | ? | 데이터 부족 가능 |
| D4 | - | ? | ? | 확인 필요 |

### 3. 블록밀 속도 변동 → 불량 유형별 상세 분석

**목적**: 블록밀 속도가 약한 신호라도 특정 불량 유형에서는 강한 신호일 수 있음

**분석**:
- 불량 유형별 (토션, 누워감김, 딱지, 돼지꼬리, 권취불량) 블록밀 속도 차이
- 특정 불량 유형에서만 유의한 패턴이 있는지 확인

### 4. 시간 윈도우 확장 분석

**목적**: ±30초가 아닌 ±5분/±10분 윈도우에서 Stand 14/블록밀 변동 포착

**가설**: Stand 14/블록밀 영향은 순간적이 아닌 "누적적"일 수 있음
- 수분간의 미세 변동 누적 → 불량 유발
- ±30초 단일 시점에서는 포착 불가

### 5. 현업 확인 필요 사항

| 확인 항목 | 이유 |
|----------|------|
| Stand 14/블록밀에서 기대한 구체적 불량 유형은? | 분석 초점 맞추기 |
| 해당 구간에서 최근 설비 변경/개선 이력이 있는가? | 변동성 감소 원인 파악 |
| 블록밀 자동 제어 모드 변경 이력? | 제어가 양호해서 변동이 작은 건지 확인 |
| 특정 시기(월/주)에 Stand 14 문제가 집중되었는가? | 시기별 세분 분석 |
