## 추가 요청사항

### 공정 흐름 방향성 검증

현업에서 제기한 의문:

- **정방향 가설**: 가열로 영향 → 조압연 → 사상압연 → 후공정 불량
- **역방향 가설**: 조압연/사상압연 부하 → 가열로 설정 영향
- **특정 설비**: Stand 8번 등, 가열로에서 영향 받아 중간압연/사상압연에 전파되는 경로

| 구분 | 내용 |
|------|------|
| 결과물 용도 | 분석 결과 + Top Feature 선정 → **중간 보고 자료** |
