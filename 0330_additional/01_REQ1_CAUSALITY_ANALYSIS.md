# 요구사항 #1: 인과관계 분석 (원인-결과 방향성)

## 고객 요청 원문

- **핵심 질문**: 수치 변동이 먼저인가 → 불량 발생? OR 고장/불량 발생 후 → 수동 조정으로 변동폭 커진 것?
- 현재 변동성 데이터만으로는 판단 불가
- **필요 작업**: 태그(TAG) 연결하여 시계열 전후관계 분석

## 추가 조사 필요 사항

### 1. TAG 시계열 전후관계 분석

**목적**: 변동 발생 시점과 불량 발생 시점의 선후 관계를 TAG 단위로 규명

**방법**:
- 현재 ±30초 단일 시점 매칭 → **±5분/±10분 윈도우로 확장**
- 불량 발생 전 태그 변동 추이 vs 불량 발생 후 태그 변동 추이 비교
- 이벤트 기반 시계열 분석 (Event Study 방법론)

**분석 대상 태그**:
- 가열로 압력 (확정 인자)
- PR3 토크 (확정 인자, D5-D10)
- MAIN_GAS_FLOW (315분석 1위)
- 균열대 Z1/Z2 온도 (역설적 패턴)
- Stand 8~14 토크/속도 (현업 지목)

### 2. Granger 인과 검정 코일 단위 재실행

**목적**: 일별 집계에서 유의했던 Granger 결과를 코일 단위에서 재검증

**대상**:
- 가열 상부 온도 → 불량 (일별 p=0.002, 코일 미실행)
- MAIN_GAS_FLOW → 불량 (315분석에서 미실행)
- 가열로 압력 → 토크 변동 (교차 인과)

### 3. 정지 후 불량 패턴 인과 방향 확정

**목적**: "정지 → 불량" vs "불량 → 정지" 구분

**방법**:
- 정지 유형별 (계획정지 vs 비계획정지) 후속 불량률 비교
- 계획정지 후 불량이 높으면 → 정지 자체가 원인 (설비 불안정)
- 비계획정지만 불량이 높으면 → 불량이 원인 (역인과)
