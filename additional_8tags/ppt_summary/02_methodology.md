# 분석 기법 소개 (Methodology)

---

## 1. 5가지 분석 기법 비교

| 기법 | 목적 | 강점 | 판정 기준 | 민감도 |
|------|------|------|----------|--------|
| **IQR** | 통계적 이상치 탐지 | 직관적, 사이즈별 분석 가능 | 이상치율 ≥10% = 문제 | 중간 |
| **CUSUM-EWMA** | 공정 드리프트 탐지 | 미세 변화 누적 감지 | Violation ratio ≥30% = 문제 | **높음** |
| **Rolling Z-Score** | 시간 변동 이상 탐지 | 국소 변동성 감지 | 이상치율 ≥3% = 문제 | 중간 |
| **STL Residual** | 추세/계절성 분리 후 잔차 이상 | 추세 제거 후 순수 이상 탐지 | 잔차 이상치율 ≥10% = 문제 | **높음** |
| **Mahalanobis** | 다변량 카테고리 이상 탐지 | 태그 간 상관관계 고려 | 이상치율 ≥5% = 문제 | 낮음 |

### 기법별 특성 정리

- **IQR**: Q1 - 1.5×IQR ~ Q3 + 1.5×IQR 범위를 벗어나는 값. 가장 직관적이며 사이즈별 분석 가능
- **CUSUM-EWMA**: 공정 평균의 미세 이동을 누적 합으로 감지. 민감도가 높아 대부분의 태그에서 드리프트 탐지
- **Rolling Z-Score**: 24시간 윈도우 기반 이동 Z점수. 국소적 급격 변화에 효과적
- **STL Residual**: 계절성(Seasonal) + 추세(Trend) + 잔차(Residual)로 분해 후 잔차의 IQR 이상치 판별
- **Mahalanobis**: 동일 카테고리 내 태그들의 공분산 구조를 고려한 다변량 거리 기반 이상 탐지

## 2. 다기법 교차 확인 체계

### 판정 등급

| 교차 확인 수준 | 의미 | 색상 |
|--------------|------|------|
| 4기법 이상 | **확정 문제** — 모든 관점에서 이상 | 🔴 빨강 |
| 3기법 | **높은 문제** — 대다수 기법에서 이상 | 🟠 주황 |
| 2기법 | **주의** — 부분 기법에서 이상 | 🟡 노랑 |
| 1기법만 | **참고** — 단일 기법 민감도 가능성 | ⚪ 회색 |

### 교차 확인의 중요성

> CUSUM은 민감도가 매우 높아 대부분의 태그에서 드리프트를 탐지합니다 (평균 violation ratio 72%).
> STL도 잔차 기반으로 높은 탐지율을 보입니다 (문제 태그 비율 96~100%).
> 따라서 **IQR + Rolling-Z** 에서도 동시에 문제인 태그가 실질적으로 중요한 이상 신호입니다.

## 3. 데이터 필터링

분석 전 4종 필터를 적용하여 정상 운전 구간만 분석합니다:

| 필터 | 설명 | 제거 비율 |
|------|------|----------|
| RUN_ONLY | 압연 중 데이터만 사용 | 가변적 |
| SPECIAL_OPS | 특수 운전 구간 제외 | 가변적 |
| ROLL_CHANGE | 롤 교체 구간 제외 | ~1-2% |
| COILING_TRANSIENT | 코일링 과도 구간 제외 | ~5-12% |

> 필터링 후 순수 정상 운전 데이터 기준으로 이상치를 판별하여 위양성을 최소화합니다.
