# 핵심 요약 (Executive Summary)

---

## 1. 분석 배경

- **목적**: 현업 요청 24개 IBA 태그에 대한 다기법 이상치 분석
- **기간**: 2025년 3~8월 (강종별 가용 데이터 기준)
- **대상**: 4개 강종 (B5, D4, D5, N5) × 10개 규격 (D10~D20)
- **분석 기법**: 5가지 (IQR, CUSUM-EWMA, Rolling Z-Score, STL Residual, Mahalanobis)
- **총 분석 결과**: 12,350개 파일 (차트 12,297 + 리포트 27 + JSON 26)

## 4. 카테고리별 문제 집중도

3기법 이상 교차 확인 47개 태그의 카테고리 분포:

| 카테고리 | 문제 태그 수 | 비중 | 핵심 이슈 |
|---------|------------|------|----------|
| 스탠드 속도 (06) | 15개 | 32% | STAND 8~15번 속도 전반 이상 |
| 핀치롤 (08) | 8개 | 17% | PR 2~4번 속도 확정 문제 |
| 스탠드 부하 (05) | 7개 | 15% | STAND 3~7번 부하 드리프트 |
| PR 상세 토크 (09) | 6개 | 13% | PR6~8 토크 전 기법 이상 |
| 가열로 보조설비 (03) | 5개 | 11% | 가스온도·연소공기 불안정 |
| 가열로 상부 온도 (01) | 4개 | 9% | 가열·균열대 온도 편차 |
| 기타 | 2개 | 4% | 스탠드 토크, 추출 온도 |

> **핵심**: 문제의 **64%가 밀 후반부**(스탠드 속도 + 핀치롤 + PR 토크)에 집중. 설비 정비 우선 대상입니다.
