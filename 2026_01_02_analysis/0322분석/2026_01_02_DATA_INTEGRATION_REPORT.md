## 9. 공정 데이터 → 불량 영향 요소 분석 계획

### 9.1 분석 목표

IBA 공정 센서 데이터(221개 태그, 84,919건)와 불량 데이터(66건/4,952건 생산)를 연결하여 **불량에 영향을 미치는 공정 요소**를 식별.

### 9.2 데이터 분석 가능성 평가

| 항목 | 상태 | 비고 |
|------|------|------|
| IBA 센서 데이터 | 충분 | RUN 30,923건, 221개 태그 |
| 생산-IBA 시간 정합 | 가능 | 4,952번들 전부 IBA 기간 내 |
| 불량 표본 크기 | 소표본 주의 | 66건 (강종별 분리 시 8~21건) |
| 기존 분석 인프라 | 풍부 | 70+ 기법, 스크립트 완비 |

**결론**: 분석 가능. 단, 66건 소표본이므로 **전체 강종 통합 분석**을 1차로 수행 후 세분화.

### 9.3 핵심 제약 및 전략

- 불량 66건은 통계적 소표본 → 강종별 분리 시 검정력 저하
- IBA-불량 매칭은 **일(day) 단위 집계** 방식 (기존 분석 패턴)
- 기존 분석(2023~2025)에서 A등급(결정적) 태그 0개, B등급(보조) 태그 21개 → 단일 예측 변수 없음, 다변량 앙상블 접근 필요
- **전략**: 접근법 A (전체 강종 통합) 우선, 유의미한 패턴 발견 시 강종별 세분화

### 9.4 분석 단계 (5 Phase)

#### Phase 1: 데이터 검증 및 기초 프로파일링

| 작업 | 내용 |
|------|------|
| IBA-불량 매칭 검증 | 불량 발생일에 IBA RUN 데이터 존재 확인, 일별 통합 데이터프레임 생성 |
| 태그 품질 확인 | 221개 태그 중 RUN 상태에서 분산 있는 유효 태그 필터링 |
| 불량 패턴 기초 분석 | 유형별 시간대/요일/교대 분포, 강종×사이즈별 불량률, 정지이력 근접성 |

#### Phase 2: 상관 분석 (통계적 방법)

| 작업 | 기법 | 기존 스크립트 |
|------|------|-------------|
| 일별 집계 상관 | Pearson + Spearman (p<0.05) | `scripts/analyze_defect_correlation.py` |
| 시차 상관 | CCF (lag 0~7일) | `scripts/comprehensive_defect_analysis.py` |
| 인과 분석 | Granger causality (maxlag=7) | `scripts/additional_methods/05_granger_causality.py` |

#### Phase 3: 불량/정상 비교 분석

| 작업 | 내용 |
|------|------|
| 고불량일 vs 저불량일 | Mann-Whitney U 검정으로 태그 차이 식별 |
| 번들 단위 매칭 | 불량 66건 ±10분 IBA vs 정상 200건 ±10분 IBA 비교 |
| TRANS 전환 구간 집중 | 기존 분석에서 이상치 100% TRANS 상태 → 2026 재검증 |

#### Phase 4: 머신러닝 기반 분석

| 작업 | 기법 | 기존 스크립트 |
|------|------|-------------|
| Feature Importance | SHAP (RF/XGBoost) | `scripts/additional_methods/04_shap.py` |
| 이상 탐지 | Isolation Forest | `scripts/additional_methods/01_isolation_forest.py` |
| 패턴 그룹핑 | K-means 클러스터링 | `scripts/comprehensive_analysis/08_clustering_analysis.py` |

#### Phase 5: 종합 및 리포트

| 작업 | 내용 |
|------|------|
| 태그 종합 랭킹 | 상관계수 + Granger p값 + SHAP + 이상탐지 일치율 → composite score |
| 기존 결과 비교 | 2023~2025 B등급 21개 토크 태그와 2026 결과 비교 |

**공정적 해석**:

1. **빌렛 추출 온도 +32.5°C**: 빌렛 추출 온도 상승은 가열 불균일(온도 편차 확대)의 간접 지표일 수 있으며, 정지 후 가열로 체류 시간 증가에 의한 과열일 가능성도 있음. 직접 인과보다 confounding 변수로서의 해석이 더 합리적.

2. **중간 스탠드(4, 7, 9번) 토크 +4~7%**: 압연 하중 증가 = 소재 저항 변화(온도 불균일, 재질 편차) 또는 패스 스케줄 이탈. 특히 Stand 4 (+7.2%)가 최대 차이.

3. **방향 일관성**: 유의하지 않지만 Stand 1~10 토크가 거의 전부 불량일에 높은 방향 → 전반적 압연 부하 상승.

**근거**: 불량일은 **"고온 + 고토크" 조건**. 가열로 추출 온도 과열 방지와 초기~중간 스탠드 압연 하중 모니터링이 품질 개선 우선 과제.
