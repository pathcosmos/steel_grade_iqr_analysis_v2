## 1. 분석 전체 구조

본 프로젝트는 DH Steel 평택공장의 2026년 1~2월 공정-불량 관계를 규명하기 위해, **2단계 분석**을 수행했습니다. 1단계 결론의 일부가 2단계에서 수정되었으며, 이는 분석 방법론의 정밀도가 단계적으로 향상된 결과입니다.

```
[1단계: 일별 집계 분석]
  22일간 일별 평균/표준편차 vs 일별 불량률
  5가지 독립 기법으로 교차 검증
  → 결론 3가지 도출

      ↓ 역인과 의심 → 검증 필요

[2단계: 코일 단위 분석]
  5,035건 개별 번들의 생산 시점(±30초) IBA 매칭
  OPERATION_STATUS 필터(RUN/TRANS/IDLE)
  강종/규격별 confounding 검증
  → 1단계 결론 중 2개 수정, 신규 인자 3개 확정
```

## 3. 분석 기법 체계

### 3.1 1단계: 일별 집계 분석 (5가지 기법)

| # | 기법 | 질문 | 강점 | 한계 |
|---|------|------|------|------|
| 1 | **Pearson/Spearman 상관** | "태그와 불량이 같이 움직이는가?" | 직관적, 방향과 강도 파악 | 선형 관계 위주, 인과 불확정 |
| 2 | **Granger 인과 검정** | "태그 변화가 불량에 선행하는가?" | 시간 순서 고려 | 진짜 인과가 아닌 예측 가능성 |
| 3 | **Mann-Whitney U 검정** | "불량일과 정상일의 차이가 우연인가?" | 비모수, 분포 가정 불필요 | 소표본(11 vs 11) 검정력 제한 |
| 4 | **Random Forest / XGBoost** | "불량 예측 시 어떤 태그를 보는가?" | 비선형 관계 포착 | 해석 복잡 |
| 5 | **SHAP 분석** | "각 태그가 예측에 기여하는 방향과 크기?" | 개별 태그 영향 분해 | ML 모델 의존 |

**교차 검증 원리**: 5가지 기법이 **독립적으로** 같은 결론을 내리면 높은 신뢰도를 부여

### 3.2 2단계: 코일 단위 분석 (4가지 기법)

| # | 기법 | 질문 | 1단계 대비 개선점 |
|---|------|------|-----------------|
| 1 | **코일-IBA 시간 매칭** | "이 번들이 만들어지던 순간의 센서값은?" | 역인과 제거 (±30초 매칭) |
| 2 | **OPERATION_STATUS 필터** | "정상 가동 중에도 이 차이가 유지되는가?" | TRANS/IDLE 허위 신호 제거 |
| 3 | **Mann-Whitney (코일 단위)** | "코일 단위에서도 유의한가?" | n=22 → n=5,035로 검정력 대폭 향상 |
| 4 | **Confounding 검증** | "규격 차이 탓은 아닌가?" | Simpson's Paradox 확인 |

### 3.3 두 단계의 관계

```
[1단계 결론]                [2단계 검증]              [최종 판정]
스탠드 토크 변동 (5/5)  →  RUN 필터 → 소멸           → 역인과
빌렛 온도 +32.5°C (3/5) → 코일 단위 → 비유의(p=0.877) → 역인과
정지 후 2시간 (OR=3.0)  →  TRANS 분석 → 부분 유지     → 근거 변경
                          PR3 토크 → 신규 확정        → D5-D10 한정
                          가열로 압력 → 신규 확정      → 전 강종
                          TRANS/IDLE → 신규 확정       → 전 유형
```

## 4. 데이터 필터 체계

### 4.1 필터가 필요한 이유

IBA 데이터의 84,919건 중 **63.6%가 비가동(TRANS/IDLE) 상태**입니다. 이 데이터를 분석에 포함하면 센서값(특히 토크)이 0으로 기록되어 결과가 왜곡됩니다.

### 4.2 필터 종류와 적용 순서

```
[원시 데이터: 84,919건 (100%)]
     ↓
[OPERATION_STATUS 필터: RUN만 선택]
     ↓
[RUN 데이터: 30,923건 (36.4%)]
     ↓
(선택적) roll_change, coiling_transient 추가 필터
     ↓
[분석 대상 데이터]
```

### 4.3 필터 프리셋

| 프리셋 | 필터 조합 | 잔존율 | 용도 | 2026 특이점 |
|--------|----------|--------|------|------------|
| P0_RAW | 없음 | 100% | 원시 확인 | - |
| P1_BASIC | run_only | 36.4% | 기본 분석 | **P2와 동치** |
| **P2_OPTIMAL** | run + special_ops | 36.4% | **본 분석 사용** | P1과 동치 |
| P3_STRICT | 전체 4개 | ~25% | 엄격 분석 | - |

> **2026 데이터에서는 P1 = P2**: RUN 상태이면 이미 가열로도 HOT(≥800°C)이므로 special_ops 필터가 추가 효과 없음

### 4.4 코일 단위에서의 필터

코일 단위 매칭(±30초)에서도 OPERATION_STATUS 필터는 **필수**입니다.

| 필터 | 코일 단위 필요성 | 근거 |
|------|:---:|:---|
| **RUN 필터** | **필수** | 불량 50%가 비-RUN, 토크 허위 신호 생성 |
| P2/P3 추가 | 불필요 | RUN만으로 충분 |
| roll_change | 불필요 | 단일 시점 매칭이므로 과도 구간 해당 없음 |
| coiling_transient | 불필요 | 동일 이유 |

## 5. 강종/규격별 분석 체계

### 5.1 왜 강종/규격별 세분화가 필요한가?

전체 데이터를 하나로 분석하면 아래 문제가 발생합니다:

1. **규격별 baseline 차이**: PR3 토크가 D5-D10에서 23.4, N5-D20에서 69.4 (3배 차이)
2. **Simpson's Paradox**: 전체에서 유의한 효과가 하위 그룹에서 사라지거나 반전
3. **강종별 메커니즘 차이**: D5는 가열 균일성, N5는 후반 스탠드가 핵심

### 5.2 confounding(교란 변수) 검증 방법

```
[Step 1] 전체 풀링 분석
  "불량 번들의 PR3 토크가 정상보다 -26% 낮다" (p<0.001)

[Step 2] 규격별 세분화
  D5-D10 내: -51.6% (p=0.004)  → 진짜 효과
  N5-D16 내: -16.7% (p=0.118)  → 비유의
  D4-D16 내: 0.0% (p=0.076)   → 비유의

[Step 3] confounding 비율 계산
  전체 효과 중 42%가 규격 구성비 차이에 의한 것
  → PR3 효과는 D5-D10에서만 실재
```

### 5.3 confounding 검증 결과 요약

| 태그 | confounding | 의미 | 적용 범위 |
|------|:-----------:|------|----------|
| **가열로 압력** | **14%** | 순수 효과 86% — 매우 신뢰 | **전 규격 적용 가능** |
| **PR3 토크** | **42%** | 절반 가까이 규격 차이 | **D5-D10에서만 확정** |
| STAND_9 토크 | - | 방향 반전 (Simpson's Paradox) | 신호 아님 |

### 5.4 강종별 핵심 인자 요약

| 강종 | 핵심 인자 | 고유 특성 |
|------|----------|----------|
| **D4** | 가열로 압력 (p=0.004) | 로압 민감도 가장 높음, D16 불량률 13.33% |
| **D5** | PR3 토크 (p<0.001), 균열대 하부온도 (p=0.024) | 가열 균일성이 품질 핵심 |
| **N5** | PR3 토크 (p=0.028), 후반 스탠드 토크 | STAND_14 방향이 D5와 반대 |
| **B5** | 불량 2건으로 분석 불가 | 데이터 축적 필요 |

## 6. A/B 라인 분석 현황

### 6.1 현재 상황

2026년 CSV에는 **라인(A/B) 구분 컬럼이 누락**되어 있습니다.

| 데이터 기간 | 라인 정보 | 상태 |
|------------|----------|------|
| 2023~2025 | coil_result에 `라인` 컬럼 존재 | 분석 가능 |
| **2026** | **coil_result에 라인 컬럼 없음** | **분석 불가** |

### 6.2 라인별 분석이 중요한 이유

- A라인과 B라인은 **설비 구성이 다를 수 있음** (핀치롤, 냉각대 등)
- 특정 라인에서만 발생하는 불량 패턴이 있을 수 있음
- 근무조(A/B/D)와 라인(A/B)의 교차 분석이 가능해짐

### 6.3 현재 가능한 대체 분석: 근무조별

라인 정보 대신 **근무조(A/B/D)**별 분석을 수행했습니다.

| 근무조 | 불량률 | 전체 대비 | 특징 |
|--------|--------|----------|------|
| **A조** | **2.05%** | **1.54배** | 가장 높은 불량률 |
| B조 | 1.08% | 0.81배 | - |
| D조 | 0.94% | 0.71배 | 가장 낮은 불량률 |

### 6.4 후속 조치

| 항목 | 필요 조치 | 기대 효과 |
|------|----------|----------|
| 라인 정보 보충 | 별도 MES 시스템에서 라인 컬럼 확보 | A/B 라인별 불량 패턴 분석 가능 |
| 라인x근무조 교차 | 라인 확보 후 근무조와 교차 분석 | 라인-조 조합별 위험도 파악 |
| 라인x규격 교차 | 라인 확보 후 규격과 교차 분석 | 라인별 규격 특성 차이 파악 |

## 7. 결론 변경 이력 — 왜 결론이 바뀌었는가?

### 7.1 변경 이력표

| # | 항목 | 1단계 판정 | 2단계 판정 | 변경 사유 |
|---|------|----------|----------|----------|
| 1 | 스탠드 토크 변동 | **확정** (5/5 기법 일치) | **역인과** | RUN 필터 시 차이 완전 소멸 (p=0.259) |
| 2 | 빌렛 온도 +32.5°C | **합리적 추정** (p=0.026) | **역인과** | 코일 단위 비유의 (p=0.877) |
| 3 | 가열 상부 온도 선행 | **합리적 추정** (Granger p=0.002) | **허위 상관** | 코일 단위 비유의 (p=0.174) |
| 4 | 정지 후 2시간 위험 | 확정 (OR=3.0) | **부분 유지** | TRANS/IDLE 상태 자체가 핵심 |
| 5 | PR3 토크 부족 | 미평가 | **확정 (D5-D10)** | RUN p=0.000011, OR=15.7 |
| 6 | 가열로 압력 저하 | 미평가 | **확정 (전 강종)** | RUN p=0.000021, confounding 14% |
| 7 | TRANS/IDLE 상태 | 미평가 | **확정** | 불량률 5.5배 |

### 7.2 변경의 기술적 원인

**핵심: 분석 단위의 차이가 결론을 바꿈**

| 분석 단위 | 왜 결론이 달라지는가? |
|----------|---------------------|
| **일별 (22일)** | 같은 날의 불량→정지→센서변동이 "센서변동→불량"으로 착각됨 |
| **코일 (5,035건)** | 개별 번들의 생산 시점만 보므로 역인과 경로가 차단됨 |

**추가 결론 변경 원인: OPERATION_STATUS 필터**

| 필터 적용 | 효과 |
|----------|------|
| **필터 미적용** | TRANS/IDLE의 토크 0값이 불량 그룹 평균을 끌어내림 → 허위 신호 |
| **RUN만 적용** | 정상 가동 중에도 유의한 차이가 남는 태그만 진짜 원인 |

### 7.3 이번 사례의 교훈

> **일별 집계의 근본적 한계가 실증되었습니다.**

1. **역인과**: 불량→정지→센서변동이 일별 집계에서 "센서변동→불량"으로 나타남
2. **Simpson's Paradox**: 전체에서 유의한 효과가 규격별로 보면 사라지거나 반전
3. **OPERATION_STATUS 교란**: 비가동 센서값이 분석을 왜곡

> **향후 모든 공정-품질 분석은 코일 단위 시간 매칭 + OPERATION_STATUS 필터링을 기본으로 해야 합니다.**

## 부록 A: 분석 기법 용어 해설

| 용어 | 설명 | 쉬운 비유 |
|------|------|----------|
| **Pearson 상관** | 두 변수의 선형 관계 강도 (r=-1~+1) | "체중이 늘면 혈압도 오르는가?" |
| **Spearman 상관** | 순위 기반 상관 (비선형에도 적용) | "성적 순위와 키 순위가 관련 있는가?" |
| **Granger 인과** | 과거값이 미래를 예측하는 데 도움되는가? | "어제 비가 오면 오늘 우산 판매가 늘까?" |
| **Mann-Whitney U** | 두 그룹의 차이가 우연인가 실제인가? | "약을 먹은 그룹이 안 먹은 그룹보다 나은가?" |
| **Random Forest** | 여러 결정 트리의 다수결 예측 | "100명의 전문가가 투표" |
| **XGBoost** | 이전 트리의 실수를 다음 트리가 보완 | "선생님이 틀린 문제를 계속 복습" |
| **SHAP** | 각 입력이 예측에 기여하는 크기와 방향 | "이 환자의 진단에 각 검사가 얼마나 기여했나?" |
| **역인과** | 원인과 결과가 뒤바뀌어 보이는 현상 | "소방차가 많은 곳에 불이 많다 → 소방차가 불을 일으킨다?" |
| **Simpson's Paradox** | 전체 경향이 부분에서 반전되는 현상 | "약이 전체적으로 효과적이지만, 남녀 각각에서는 비효과적" |
| **confounding** | 두 변수 관계를 왜곡하는 제3 변수 | "아이스크림 판매와 익사 사고가 상관 → 진짜 원인은 여름(기온)" |
| **Odds Ratio** | 위험 구간의 발생 확률 / 안전 구간의 발생 확률 | "3.0 = 3배 더 위험" |
| **p값** | 관찰된 차이가 우연일 확률 | "0.01 = 우연일 확률 1%" |
