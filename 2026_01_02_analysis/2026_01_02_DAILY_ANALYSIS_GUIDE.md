### 2.3 IBA 태그란?

IBA(Intelligent Bus Analyzer) 시스템은 압연 라인의 각 설비에 부착된 센서에서 1분마다 값을 수집합니다. 하나의 **태그(tag)**는 하나의 센서 측정값을 의미합니다.

**주요 태그 카테고리**:

| 카테고리 | 태그 수 | 예시 | 측정 대상 |
|----------|---------|------|----------|
| 가열로 온도 | 9개 | 가열 상부/하부 온도, 균열대 온도 | 빌렛 가열 상태 |
| 가열로 부대 | 10개 | 가열로 압력(로압), 빌렛 추출 온도 | 가열로 운전 조건 |
| 스탠드 토크 | 16개 | STAND_1~14 실제 토크 | 각 압연기의 부하 |
| 스탠드 속도 | 15개 | STAND_1~14 실제 속도 | 압연 속도 |
| 핀치롤 | 12개 | PINCHROLL_2~4 토크/속도 | 권취 직전 장력 제어 |
| 냉각수 | 2개 | 냉각수 유량/온도 | 냉각 조건 |

## 3. 데이터 필터링

### 3.1 왜 필터링이 필요한가?

IBA 데이터에는 설비가 가동 중이지 않은 시간(정지, 전환, 유휴)의 센서값도 포함됩니다. 예를 들어 압연기가 멈춰 있으면 스탠드 토크가 0으로 기록되는데, 이 값을 분석에 포함하면 결과가 왜곡됩니다.

### 3.2 OPERATION_STATUS (가동 상태) 분류

IBA 데이터의 매 행(1분 단위)에 아래 3가지 상태를 부여합니다.

| 상태 | 의미 | 판정 기준 | 비율 |
|------|------|----------|------|
| **RUN** | 정상 가동 중 | STAND_1 속도 > 0 AND 재료 감지 ON | 36.4% |
| **TRANS** | 전환 중 (시작/정지 경계) | 속도 > 0 BUT 재료 미감지 | 8.6% |
| **IDLE** | 정지/유휴 | 속도 = 0 | 55.0% |

### 3.3 4가지 필터 유형

| 필터 | 쉬운 설명 | 제거 대상 | 적용 태그 |
|------|----------|----------|----------|
| **run_only** | "설비가 실제로 돌아가는 시간만 분석" | IDLE, TRANS 구간 | 전체 208개 |
| **special_ops** | "압연기+가열로 모두 가동 중인 시간만" | 가열로 미가동 구간 | 전체 208개 |
| **roll_change** | "롤 교체 시 급변하는 구간 제거" | 롤 교체 직후 과도 구간 | 스탠드+핀치롤 58개 |
| **coiling_transient** | "권취 시작/종료 시 가감속 구간 제거" | 권취 과도 구간 | 핀치롤 24개 |

### 3.4 필터 프리셋 (조합)

실제 분석에서는 개별 필터를 하나씩 켜는 대신, 미리 정의된 **프리셋**을 사용합니다.

| 프리셋 | 필터 조합 | 데이터 잔존율 | 용도 |
|--------|----------|-------------|------|
| **P0_RAW** | 없음 | 100% | 원시 데이터 확인 |
| **P1_BASIC** | run_only | ~36% | 기본 분석 |
| **P2_OPTIMAL** | run_only + special_ops | ~36% | **본 분석에서 사용** |
| **P3_STRICT** | 4개 전부 | ~25% | 엄격 분석 |

> **2026 데이터 특이점**: P1과 P2가 동일한 결과를 냅니다. `OPERATION_STATUS='RUN'`이면 이미 가열로도 가동 중(HOT)이기 때문입니다. 따라서 run_only 필터 하나만으로 P2 수준의 필터링이 달성됩니다.

### 3.5 태그 카테고리별 필터 적용표

모든 태그에 모든 필터를 적용하는 것이 아니라, **태그 특성에 맞는 필터만 적용**합니다.

| 카테고리 | 태그 수 | run_only | special_ops | roll_change | coiling |
|----------|---------|:--------:|:-----------:|:-----------:|:-------:|
| 가열로 온도 | 9 | O | O | - | - |
| 가열로 부대 | 10 | O | O | - | - |
| 스탠드 토크 | 16 | O | O | **O** | - |
| 스탠드 속도 | 15 | O | O | **O** | - |
| 핀치롤 | 12 | O | O | **O** | **O** |
| 냉각수 | 2 | O | O | - | - |

- 스탠드/핀치롤에는 roll_change 필터를 추가로 적용하여 롤 교체 직후 급변값을 제거
- 핀치롤에는 coiling_transient 필터를 추가로 적용하여 권취 과도 구간을 제거

## 4. 분석 기법 5종 상세 설명

본 분석에서는 **5가지 독립적인 분석 기법**을 사용했습니다. 서로 다른 각도에서 동일한 질문("어떤 공정 조건이 불량에 영향을 미치는가?")에 답하며, 여러 기법이 같은 결론을 내리면 신뢰도가 높아집니다.

### 4.1 기법 1: Pearson/Spearman 상관 분석

**쉬운 설명**: "두 값이 같이 움직이는 정도를 수치화"

**방법**:
- 22일간 각 태그의 일별 평균(avg)과 표준편차(std)를 계산
- 일별 불량률과의 상관계수(r)를 산출
- Pearson(선형 관계)과 Spearman(순위 관계) 두 가지로 교차 확인

**해석 기준**:

| 상관계수(r) | 해석 |
|------------|------|
| 0.0 ~ 0.3 | 약한 상관 |
| 0.3 ~ 0.6 | 중간 상관 |
| **0.6 ~ 1.0** | **강한 상관** |

**핵심 발견**:
- 상위 6개 태그가 모두 **스탠드 토크의 변동성(std)** — 토크 값의 "흔들림"이 불량과 동반
- STAND_8 토크 std가 r=+0.623으로 1위
- **변동성(std) 유의 태그 37개 vs 평균(avg) 유의 태그 18개** — 절대 수준보다 "불안정"이 중요

**이 기법의 한계**:
- 상관 ≠ 인과: "함께 움직인다"가 "원인이다"를 의미하지 않음
- 일별 집계 특성상 역인과 가능성 존재 (코일 단위 분석에서 검증)

### 4.2 기법 2: Granger 인과 검정

**쉬운 설명**: "A의 과거값이 B의 미래를 예측하는 데 도움이 되는가?"

**방법**:
- 시간 순서를 활용하여, 특정 태그의 과거값(1~5일 전)이 미래 불량률을 예측하는 데 통계적으로 유의한지 검정
- 단순 상관과 달리 **시간적 선후관계**를 고려

**핵심 발견**:

| 순위 | 태그 | 선행 일수 | p값 | 해석 |
|------|------|----------|------|------|
| 1 | 가열 상부 온도 | 2일 | 0.002 | 가열 온도 변화 → 2일 후 불량 가능 |
| 2 | STAND_9 토크 | 2일 | 0.007 | 토크 이상 → 2일 후 불량 가능 |
| 3 | STAND_8 토크 | 1일 | 0.014 | 전일 토크 이상 |

**이 기법의 한계**:
- "Granger 인과"는 "진짜 인과"가 아닌 "예측 가능성"을 의미
- 22일이라는 짧은 시계열에서의 검정력이 제한적
- 후속 코일 단위 분석에서 가열 상부 온도의 인과 판정이 수정됨

### 4.3 기법 3: Mann-Whitney U 검정

**쉬운 설명**: "불량이 발생한 날과 그렇지 않은 날의 공정 조건이 실제로 다른가, 아니면 우연인가?"

**방법**:
- 22일을 **불량일(11일)**과 **무불량일(11일)**로 분류
- 각 태그의 일별 통계값이 두 그룹 간에 유의미하게 다른지 비모수 검정
- p값 < 0.05이면 "우연으로는 설명하기 어려운 실제 차이"

**핵심 발견**:

| 태그 | 불량일 평균 | 무불량일 평균 | 차이 | p값 |
|------|-----------|-------------|------|------|
| 빌렛 추출 온도 | 1,006°C | 973°C | **+32.5°C** | 0.026 |
| STAND_4 토크 | 52.52 | 48.98 | +7.2% | 0.030 |
| STAND_1 토크 std | 12.72 | 10.81 | +17.7% | 0.015 |

> 불량일은 **"고온 + 고토크 + 고변동"** 조건

**이 기법의 한계**:
- 11일 vs 11일이라는 소표본으로 검정력이 제한적
- 후속 코일 단위 분석에서 빌렛 온도 차이는 비유의로 판정됨 (p=0.877)

### 4.4 기법 4: 머신러닝 (Random Forest / XGBoost)

**쉬운 설명**: "컴퓨터가 불량을 예측할 때 어떤 태그를 가장 많이 참고하는가?"

**방법**:
- Random Forest와 XGBoost 두 가지 앙상블 모델 학습
- 모델이 불량 여부를 예측할 때 각 태그에 부여하는 **중요도(Feature Importance)**를 추출
- 두 모델에서 공통으로 중요하게 뽑힌 태그가 가장 신뢰성 높음

**핵심 발견** (양 모델 만장일치 4개 태그):
1. STAND_12 토크 변동(std)
2. STAND_1 토크 변동(std)
3. STAND_12 속도 변동(std) — **ML에서 새롭게 발견된 지표**
4. STAND_9 속도 변동(std)

> 통계 분석과 **독립적으로 같은 결론** (토크 변동성 중요) + **속도 변동성이라는 새 지표 추가 발견**

### 4.5 기법 5: SHAP 분석

**쉬운 설명**: "각 태그가 불량 확률을 높이는 방향인가, 낮추는 방향인가, 그리고 그 크기는?"

**방법**:
- XGBoost 모델에 SHAP(SHapley Additive exPlanations) 적용
- 각 태그가 예측 결과에 기여하는 **방향(양/음)**과 **크기**를 개별적으로 분해
- Feature Importance는 "얼마나 중요한가"만 알려주지만, SHAP은 "어떻게 영향을 미치는가"까지 보여줌

**통계 기법과 ML/SHAP의 차이**:

| 항목 | 상관/검정 (기법 1~3) | ML/SHAP (기법 4~5) |
|------|---------------------|---------------------|
| 접근 방식 | "이 태그가 불량과 관련이 있는가?" | "불량을 예측하려면 어떤 태그를 봐야 하는가?" |
| 강점 | 통계적 유의성 판단 (p값) | 비선형 관계, 태그 간 상호작용 포착 |
| 약점 | 선형 관계 위주, 태그 간 상호작용 무시 | 해석이 상대적으로 복잡 |

### 4.6 5가지 기법 교차 검증 요약
